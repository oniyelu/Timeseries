Time series analysis of malaria in pregnancy, using Wavelet transform and ARIMA models. Author-generated code being made available without restrictions upon publication of the work. 
The preprocessed dataset collected from Nigerian Malaria Data Repository (NMDR) was transformed using square-root transformation, cleaned for outliers, missing values handled using Kalman smoothen imputation and formatted into structured time-series entries. It was used in the work to i) examine the variability of monthly Malaria confirmed pregnant women cases (dataMIP) and the general confirmed uncomplicated malaria cases (datam) across Nigeria 6 geopolitical zones from January 2015 to January 2025, ii) evaluate temporal trends, leading to the short-term forecast of MIP incidence. The monthly periods per local government area (yearSORT, LGAsort) of each State for each region are also included in the data. Access can be granted upon request to verified researchers, following necessary approvals. Researchers must submit a formal request with justification.
